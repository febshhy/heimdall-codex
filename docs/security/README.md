# Security findings

Record security observations from **real project surfaces**, with evidence, impact, uncertainty, and follow-up. This starter includes no findings and does not establish a security posture for an application.

Copy [the finding template](FINDING_TEMPLATE.md) only when there is an actual issue, observation, or investigation to record. Protect sensitive evidence; do not place secrets, tokens, personal data, or exploit details in public documentation.

If a finding changes mandatory product behavior, update the relevant requirements through the project's approval process. If it leads to a durable technical decision, create an ADR.
