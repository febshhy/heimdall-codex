# Research and open questions

Keep research that another engineer can use to make or review a decision. Link primary evidence, state assumptions, and distinguish observed facts from hypotheses.

Research is **not** an approved requirement or accepted architecture decision. When a conclusion becomes authoritative, record it in the corresponding requirement or ADR and link back to the evidence.

Use [the question template](QUESTIONS_TEMPLATE.md) when an unresolved question is important enough to track. Do not copy all prompts into the project as though they are real open issues.
