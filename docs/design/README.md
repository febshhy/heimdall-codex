# Design records

Use this folder for **project-specific interface and content decisions** when multiple parts of an application need consistent rules.

[The system template](SYSTEM_TEMPLATE.md) provides optional headings for typography, colors, components, language, interaction states, and verification. Copy it to `system.md` only after the project needs shared design rules. Delete unused sections and record decisions supported by actual product requirements, user needs, or tested constraints.

The design system describes presentation and terminology. It does not replace the application's state transitions, domain invariants, accessibility testing, or requirements.

A template or unreviewed mockup is not an approved design. Record meaningful exceptions and checks performed; do not claim accessibility or responsiveness solely because a template includes those headings.
